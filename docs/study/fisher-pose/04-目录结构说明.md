# 姿势专题文件边界

这里只列本轮已核对的文件，不冒充完整仓库导览。

| 上游路径 | 在本专题中的职责 | 本轮状态 |
| --- | --- | --- |
| `web/editor/freepose.mjs` | Fisher 编辑界面适配：构建 viewer、绑定滑杆、预设、历史回调 | 选定片段已读 |
| `web/vnccs/vnccs_pose_studio_core.mjs` | 第三方核心在 Fisher 中的版本：骨架、拾取、IK/FK、标记、快照 | 核心手动编辑路径部分精读 |
| `web/vnccs/vnccs_hand_presets.mjs` | 手指姿势四元数数据 | 全文已读 |
| `web/vnccs/TransformControls.mjs` | 通用旋转控件及手势计算 | 旋转交互路径已读，通用绘制几何未展开 |
| `web/editor/movement-gizmo.mjs` | 整个人移动，不修改骨骼姿势 | 全文已读 |
| `web/editor/common-poses.mjs` | 方向式常用姿势描述 | 全文已读 |
| `web/editor/pose-shape.mjs`、`saved_poses.py` | 保存时的身材分离与服务器存档 | 全文已读 |
| `web/editor/studio.mjs`、`avatar.mjs`、`state.mjs` | 另一套关节点几何人偶编辑器 | 已追读手动摆姿路径，与真实蒙皮主链分开记录 |
| `web/vnccs/README.md`、`LICENSE` | 第三方来源与许可 | 已核对 |

适配层负责把用户控件连接到核心，不另造一份骨架。核心持有 `bones`、`selectedBone`、`directDrag`、`ikController` 和历史。手势数据只覆盖手指，不应误当成手腕朝向控制。

本轮不沿 Python 节点、生图、SAM 导入、相机拍摄专题扩散；也不把这个专用 MakeHuman 骨架当成 MotionDeck 任意模型的现成替换件。

例外：为闭合手动编辑的常用姿势入口，追读了其共用导入求解函数；为确认手掌朝向能力，单独读了导入中的手掌坐标系函数。没有据此宣称识别/导入专题全部读完。
