## 路线

1. 关节链配置 → 两骨解析求解 → 世界/局部旋转换算。
2. 鼠标按下、移动、松开 → 选中与旋转环 → 末端和弯曲目标同步。
3. 模型骨架、绑定姿态与蒙皮 → 手腕方向和手指手势 → 重置、历史与保存。
4. 补齐初始化、事件注册和全部手动编辑入口，形成完整姿势操作证据。
5. 学习收束后再讨论 MotionDeck 如何适配；目前不制定移植实施方案。

## 已回答的问题

- 手腕朝向：手动选腕骨旋转；导入另有 `_alignHandWorldBasis`，但没有接成手动IK的掌向约束。
- 隐藏手指：`useHandControlPopover` 控制隐藏和手表面激活；Fisher主入口明确关闭此模式，保留手指关节选取。
- 取消收尾：当前核心直接拖关节只注册down/move/up，未接cancel/丢捕获；移整个人的工具另有cancel收尾，另一关节点编辑器则同时接up/cancel/lostcapture。不能混作已完整实现。
- 极近目标、共线、反向肘和网格穿模：源码分支已读，但实际自然度、稳定性仍属于未执行的运行验证，不再伪装成“还没找到代码”。

提炼见[知识点与结论](14-知识点拆解.md)。后续如进入MotionDeck实现，须明确切换出阅读模式；目前没有待继续补读的手动编辑主链任务。
