# 全身联动隔离试验

2026-10-12。用户授权“试试吧”后实现；没有替换正式姿势编辑器，没有提交、推送或发布。

2026-10-13更新：拖动改为“局部预探 → 邻近渐进配合 → 周边渐进配合”。固定预算只保留为最高调整边界，不再从一开始全部启用。本轮没有处理旋转范围问题，旋转仍沿上一版路径。

## 入口与边界

- `http://127.0.0.1:8900/labs/motion/fullbody.html`。8900原编排入口保留，8897未重启或变更；试验没有素材库读写入口。
- 模型仅Quaternius与Mesh2Motion，沿用builtins目录、loadFiles、PoseSampler、capturePose/applyPose和自由观看适配；只在独立实例内试摆。
- 默认保持双脚位置和朝向。拖任一身体点建立当前目标；保持点同时参与求解。松开移除临时目标，下一次手势以当前姿势作为参考；保持点继续保留。
- 拖动先仅启用局部必要关节：手/肘先当前侧臂/肘，头先头颈，腿先当前侧腿，胸腰先躯干。局部目标或保持点还存在明显误差时，肩或骨盆/支撑腿逐渐参与；邻近求解仍不足才逐渐放开周边的小范围。骨盆操作中的双腿属于必要支撑，从局部阶段参与。旋转暂维持上一版路径。
- 蓝点表示位置或朝向保持；下拉选择部位可避免侧视点重叠。选择“旋转”后使用视口旋转环，同时保留所选点位置目标；拖动沿当前相机平面，深度方向需转相机再拖。
- 保持点是有限迭代目标，不是绝对固定。底部显示最大位置误差（身高百分比）、最大朝向误差、收敛状态与本次耗时。不可达或矛盾目标允许残差，不能用骨骼拉长满足目标。
- 底部同时显示当前调整范围；碰到预算且目标误差较大时显示“已到本次调整边界”。预算相对每次手势起始姿势，不是人体生理限位，也不是软刚度/加权优先级求解。不会自动扩大到无范围限制或退回旧手脚链。
- 尚无人体关节限位、偏好屈曲方向、碰撞、平衡、动作编辑或正式保存接入；可能扭转/穿插。数学收敛不能证明姿势自然或易用。

## 为什么先用现成库

使用[closed-chain-ik-js](https://github.com/gkjohnson/closed-chain-ik-js/tree/1132da3dc3ac774426e9af503e4915bc04ca413b)，固定提交`1132da3dc3ac774426e9af503e4915bc04ca413b`，包0.0.7。它替代手写联合雅可比、阻尼最小二乘、参考姿势分摊和迭代状态；仅使用core，不引入其机器人加载器/展示层。新增3个数学运行依赖（gl-matrix、linear-solve、svd-js）；维护成本是早期库API与数值性能风险，依赖限在试验适配层，正式领域协议不变。关闭SVD，使用DLS，不配置旧IK失败回退。

通过固定提交归档URL安装，不触发Git凭据选择；本次使用`npm.cmd install --save-dev --save-exact --legacy-peer-deps <固定归档URL>`，只使用core时不需要urdf-loader可选展示能力。构建命令`npm.cmd run build:fullbody-trial`；许可证及上游linear-solve元数据保存在web/licenses，源资源仍保持原署名。

## 输入 → 求解 → 输出

1. 从当前真实人偶姿势建立独立Link/Joint树，归一化世界长度。已确认19个主要身体点允许旋转，骨盆另允许平移；其他节点为刚性连接，保留原模型层级。
2. 当前目标与位置/朝向保持点通过Goal闭合连接。共享骨盆/躯干的目标合成一个求解问题，不分别调用四条手脚链。
3. `adjustmentPolicy`定义局部、邻近、周边及最高调整边界。拖动每帧先将求解增量重置到本次手势基准，局部单独预探；按最大目标剩余误差计算邻近参与，再对邻近阶段的剩余误差计算周边参与。通过Joint公开setMinLimit/setMaxLimit连续缩放邻近/周边边界；每阶段最多24轮、最多3阶段，只发布最终结果。旋转仍是原12轮路径。拖动事件按渲染帧合并。没有新增求解器、改第三方源码或复制旧IK。
4. 校验所有输出有限后再写世界旋转到原骨骼局部四元数；只有骨盆写平移，其余局部位置、缩放与父子关系保持不变。仅支持正等比骨架缩放，其他缩放明确拒绝。
5. 每次手势保存一份姿势＋保持点快照；松开记历史，Esc/失焦/后台取消并恢复；撤销最多30次手势。不会保存到默认或自定义库。

## 源码证据与落点

- `fullbody-rig.js`：现成求解器适配、显式人体骨名映射、世界姿势写回及误差测量。第三方API不进入sequence-core或保存协议。
- 上游`src/core/Solver.js:updateStructure`：合并共享关节的闭合链；`ChainSolver.js:solve`：误差/雅可比/DLS与参考姿势；`Goal.js`：位置与全部旋转轴分开，不能只设单个旋转轴约束。
- 稳定性修正核对同提交`Joint.js:setDoFValue/setMinLimit/setMaxLimit`以及`ChainSolver.js:lockLimitedJointAngles`：数值赋值限幅、触边自由度从当前轮可动集合移除；下一次solve清除当前轮锁定状态。API没有逐关节软刚度，不能把单次预算写成成熟的加权人体求解。
- `fullbody.js`：隔离试摆、指针平面目标、TransformControls旋转目标、保持点及事务取消；不直接拖原骨骼平移。
- 构建脚本`build-fullbody-trial.mjs`只构建试验bundle，不重建正式motion.bundle。

### 渐进规则与参考基准

- 邻近参与：`smoothstep((局部残差-0.003)/0.035)`，误差单位为身高比例；0.3%以内不参与，约3.8%达到配置上界。周边参与根据邻近阶段残差，`smoothstep((邻近残差-0.015)/0.06)`。阈值是试验参数，不是物理拉力。
- 每阶段残差取全部目标/保持点的最大位置误差；朝向冲突按身高10%等效力臂换算，用于检测无法兼顾的保持目标。包括有限轮求解未完全收敛的误差，不宣称测出严格几何可达距离。
- 开始手势时固定初始世界刚性帧。每帧从该基准重求，不用上一帧的参与程度递增；鼠标收回后重新测局部残差，参与可降回零。松手保留当前姿势，下一次手势用新的起始姿势。
- 界面显示“局部调整”“邻近配合百分比”“周边配合百分比”，百分比是当前层的边界启用程度，不是拉力或真实运动分摊百分比。

## 已验证

`node --test tests/web/motion-fullbody.test.mjs`：两种真实骨架、根旋转与等比缩放；保持双脚拖胸，两侧腿参与，目标误差小于身高1.5%；局部骨长/缩放/父子关系不变；快照恢复、头部位置＋旋转目标、只保持朝向、不可达目标残差、非等比缩放拒绝。定向小幅胸部拖动位置误差最大约身高0.10%，不是所有姿势的保证。

稳定性领域回归覆盖两人偶拖手、拖膝、触边提示及所有自由度不超当前参与边界。渐进版本的内收抬手目标局部可完成，邻近/周边参与均为零，头/胸/另一只手漂移小于身高0.001%；额外6项定向测试中的2项覆盖41个逐步外拉目标、部分参与、外围配合、身体点移动不大幅突跳、拉回、相同目标10次重求不累积，以及取消恢复。有限迭代仍可能TIMEOUT；界面明确显示，不用误差小冒充收敛。

2026-10-12固定预算版历史对照：内收抬手目标的头/胸/另一只手最大漂移Quaternius约1.41%、Mesh2Motion约2.14%；不是当前版本数据。当时向外抬手目标在白模有约身高2.19%残差。现在保留可达/超范围分开测，不为降低残差放开全身；旧测试内解除全部边界的比较已由直接渐进行为断言替换，因为move每帧重新配置边界，测试手工修改边界不再能复现旧模式。

`npx.cmd playwright test --config motion-lab.playwright.config.js tests/motion-lab/fullbody-trial.spec.js`：5项Chrome真实鼠标测试。原两人偶拖胸/局部拖手/撤销取消保留；新增白模同一手势内收抬手仅局部、外拉出现非0/100的邻近参与、继续外拉出现周边参与、拉回恢复局部和原位置、Esc取消。截图`output/acceptance/fullbody-progressive-near.png`与`fullbody-progressive-support.png`记录当前反馈。浏览器测试未实际拖旋转环，旋转问题没有修复。

尚待用户试摆手感、复杂连续手势、完整人体约束配置、与原交互对照，以及决定是否接入正式编辑器。当前不宣称替代成熟人体编辑产品。

## 第一轮稳定性修正（2026-10-12）

统一姿势保持参数不足以限制不同部位的联动；先试较宽的躯干配合范围仍会累积头部漂移，故按实际身体点位移收紧。最终复用现成关节限幅，给不同部位不同单次预算。无关部位保持小余量，可达目标仍能调整，远目标显式保留残差。可复用规则：摆姿势验收必须同时测目标跟随、无关部位漂移与超范围反馈，不能只看收敛或骨长。

## 渐进修正（2026-10-13）

固定边界版本仍从一开始让邻近部位参与；本轮改为按分阶段残差平滑启用边界。实际验证局部可完成则周边保持、误差增加出现中间参与程度、拉回不累积；仍待人工判断手感。需复用的验收规则：既测范围扩大，也测同手势收回与重复目标，不能只看一次最终姿势。旋转范围、完整人体限位、非自然姿势与复杂拖动稳定性仍未解决。
