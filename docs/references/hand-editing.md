# 手部直接编辑

2026-10-17，已纳入公开v0.3.0。当前采用五指统一三点拖动，无手部旋转环、滑轨、预设或独立手部面板。旧两点/逐节旋转弧方案已替换，不保留隐藏入口。

## 操作与骨链语义

源码归属：手部交互/标定/求解/约束现均在`web/labs/motion/pose/`，工具展示为`ui/pose-tools.js`。本轮只迁移路径，原数学与事务不变，见[结构扫描记录](code-structure-audit.md)。

代码整理补充：HandControls中的focusHand/createPart/selectFinger/begin-move-finish/restoreCamera分别负责取景、三点建模、选指、事务和镜头恢复。与身体共用pose-picking的最近节点分流，保留原8像素半宽；不修改FingerJointDrag、限位、姿势快照或保存格式。工具栏原DOM改由PoseTools创建，手部面板仍挂在同一工具栏中，未增加控件或改现有交互。

点手的真实模型表面进入近景，默认不显示节点。点某根手指，只显示该指两个指节与指尖三点；其他指隐藏。点空白收起且保留观察相机操作，选指不改变姿势或历史。腕点仍摆手臂，整体调整不进入手部编辑。

| 拖动点 | 唯一允许旋转的骨 | 保持不变 |
| --- | --- | --- |
| 第一指节（第二节根部） | 近节 | 近节原点、所有其他骨的局部姿态 |
| 第二指节（第三节根部） | 中节 | 中节原点与上游、所有其他骨的局部姿态 |
| 指尖 | 远节 | 远节原点与上游、所有其他骨的局部姿态 |

下游保持相对姿态，自然随父骨运动；不恢复它们的世界朝向，也不反向解整条链。骨长/缩放不变，不靠平移非根骨追鼠标。自然模式下两个末端铰链主要屈伸，不承诺任意屏幕方向都可达。

三个点共用屏幕误差步进：输入鼠标像素增量、相机投影、选中分段；输出选中一骨的受限旋转和误差反馈。小步求角度、限位后重投影；候选须降低屏幕误差且不反向。接近沿视线的退化方向可能停住，不以巨大旋转或旧追点路径兜底。两个角度增量同比缩小，不能独立截断而改变求解方向。触边后下一事件从实际姿势继续，反向不累积超调。

旧动作可能带有超出当前范围的末节扭转或反折。自然模式下，超过3像素开始真正拖动时，仅把本次选中一骨校正到合法姿态，然后以合法姿态建立屏幕锚点与角度增量基准；可能看到该节先归位。旧姿势校正量不计入鼠标单步约23°的限制，否则约55°的旧超限会让所有候选被拒绝。选中、点击、零增量、加载或自由模式均不执行这项校正；Esc/撤销精确恢复原超限姿势，不校正其他关节。角度表和指根联合限位没有随此修复放宽。

自然模式：四指根屈曲0～85°、外展±22°且随屈曲收窄；中节0～105°、远节0～75°，只屈伸。拇指根屈曲−15～65°、侧摆±40°、转向±35°，后两节分别0～65°/0～80°。拇指根屈曲附加0.4比例转向再投统一限位，比例只是工程初值，不是医学标定。自由模式无自动联动/限位，仍不改骨长。

拖动3像素开启原工作台单骨事务，松手一步历史；Esc/失焦/捕获取消回滚。返回全身恢复原镜头；保存/退出/切模型清点和选指。辅助标记在模型根外，同帧读取真实骨矩阵，媒体隐藏、不写入姿势或GLB。不修改旧素材、动作采样、协议或资料格式。

当前不提供指间/掌面碰撞、握物接触、掌部杯形变形或过渡逐帧修正；限位合法不等于无穿模，也不保证自动获得自然手势。

## 源码证据索引

- `hand-rig.js`：两实际骨架显式指骨父链与逆绑定标定；Mesh2Motion取leaf，Quaternius从远节影响≥0.5的实际蒙皮顶点测指尖。无法标定明确失败，不猜骨长。`handForHit/fingerForHit`按实际射线三角形蒙皮权重判断手/指，不用近点或大碰撞球抢掌面、前臂或空白。
- `finger-ik.js:FingerJointDrag`：segment=0/1/2明确对应唯一骨；指尖只读标定偏移，不向模型树插辅助骨。旧指尖两节CCD和世界目标入口已移除，无兼容别名/fallback。
- `hand-joint-motion.js`：关节控制角复用`projectJoint`分解/投影；屏幕有限差分、2×2阻尼、同比缩步、候选回溯验算。矩阵运算复用锁定Three 0.186.1的`Matrix3`，未引入新依赖。旧三维对齐仅在测试里显式调用已有LimbIK作为反向反例，不进入手部运行路径。
- `hand-controls.js`：手表面入口、选指后三点、原单骨手势、相机快照恢复；`BodyMarkers`同帧绘点，DOM仅透明命中。近景沿用当前选择的四种相机模式，临时解锁固定预设旋转，返回恢复原镜头；旧OrbitControls缓存补丁已移除，依据见[相机说明](camera-trackball.md)。
- `joint-limits.js`：原20主关节加双手30指节；四指联合范围保证投影幂等，拇指独立。旧姿势载入不自动投影，只有实际修改的关节应用范围。
- `tests/web/finger-ik.test.mjs`：两模型双手五指三段逐一检查仅一骨变化、上游固定、下游局部不变、骨长/缩放不变、边界及原事务取消/撤销/重做。
- `tests/web/hand-joint-motion.test.mjs`：斜视角旧反向复现、新屏幕方向不反转且不冻结全部输入、拇指联动/自由模式。
- `tests/web/hand-legacy-recovery.test.mjs`与`tests/helpers/load-rig.mjs:loadRigAsset`：从真实分发素材取得动作而非只有标定姿势；中点采样后验证超限末节解锁、恢复后继续控制、零输入不变和原事务取消/撤销/重做。网页复现保留真实末节四元数，其他关节中性以稳定实点；不能将其表述为当前用户草稿的精确回放。
- `tests/motion-lab/finger-edit.spec.js`：两模型左右手实点手/指，实际拖三个点、核对唯一骨、取消/撤销、窄窗截图和保存刷新。实际结果及独立包见[验证记录](../verification.md)。

研究及许可边界见[手部交互研究](hand-posing-research.md)。其中旋转弧为历史小样，不是当前入口；没有复制GPL参考代码、商业求解器或MANO参数。
