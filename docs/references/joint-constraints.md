# 关节约束：A1–A4 实现与使用

2026-10-17，开发源码功能，尚未发布。当前用户窗口未重启，不代表现用安装包已有此功能。后续A5防穿模、A6过渡逐帧修复不在本轮范围。

## 使用入口

进入“编辑姿势”，工具栏用并排的“自然约束／自由编辑”按钮切换，选中项淡蓝强调，不使用原生下拉菜单；超限信息是独立的低对比度标签。两内置模型默认自然约束；超限时保留受限结果，提示“已到关节边界”。反向拖立即返回。整体调整不受解剖范围限制。

旧姿势不在加载、进入编辑、切换模式、保存或撤销时自动修正。界面提示“原姿势超限 N”，命令返回具体关节；只修本次修改的关节。需要保留超限造型可显式选择自由编辑。未标定模型显示“未标定”，只提供自由编辑，不猜轴。后续手部扩展为每模型再标定30节指骨，共50节；不支持的手部单独报告handReason，其他未管理关节不冒充已约束。见[手部编辑](hand-editing.md)。

普通AI制作先查询`session.inspect.jointConstraints`及分页`rig.list`，再在`pose.setBones`请求中显式传`constraintMode:'natural'`。结果`constraints.applied`逐骨给出实际四元数、clamped、status与受限后的关节角（度）；以实际结果继续制作，不盲目反复请求超限值。`free`只覆盖该次请求，不改界面模式。旧构建不支持该参数时明确报告，不能静默降级。权限、模型/版本校验与原批量事务不变。

## A1：两模型标定

`web/labs/motion/pose/joint-limits.js`显式映射Mesh2Motion及Quaternius的躯干、锁骨、四肢和掌/脚参考点；核对唯一名称、父链、绑定矩阵、正向近似均匀缩放。骨名先用Three的sanitizeNodeName，不自行替换标点。

- 各20个主要关节：骨盆、3节脊柱、颈、头，加左右锁骨/肩/肘/腕/髋/膝/踝。
- 从`Skeleton.boneInverses`逆矩阵取得绑定世界变换，逆父绑定矩阵乘子绑定矩阵得到局部参考旋转；绝不以当前动画/当前手势当零位。
- 髋左右和骨盆至头方向建立身体参考；肘向前弯，膝向后弯，分别计算两侧局部轴。旋转轴与骨长扭转轴正交。
- 手腕利用食指/小指根部的绑定平面区分屈伸与侧偏；脚踝利用脚趾方向标定，不把人体全局XYZ当所有关节轴。
- 两个实际分发骨架均无独立twist骨；前臂旋转保留在前臂骨，没有虚构扭转分配/蒙皮能力。

`rig.list.entries[].jointLimit`返回reference/frame/bendAxis/twistAxis/ranges；范围单位为度，四元数仍局部绝对值。未知、退化、层级不符或不支持缩放均明确报告。模型加载时标定缓存不改任何节点；整体位置/朝向不参与人体限位。

## A2：肘膝统一约束

候选局部旋转 → 去绑定参考 → 转入关节坐标 → 分解摆动/扭转 → 投影活动范围 → 转回局部旋转。肘膝摆动只保留主弯曲轴，前臂轴向旋转另有限度，不把它塞进腕部或彻底锁死。恰好180°时采用确定性符号规则，使q/-q投影一致。

旋转环、拖动、AI修改最终共用`constrainBone/projectJoint`。环在触边后重设鼠标增量参考，拖动在受限结果处重建增量目标；无需把超调距离拖回来才响应反向。控件起点不是撤销真值，Esc始终恢复工作台完整事务。一次手势一步历史，错误整批回滚，沿用保存和覆盖规则。

## A3：全身范围

球关节使用关节空间摆动旋转向量的椭圆范围，再独立限制扭转，不逐轴截断原始Euler。以下是工程初始参数，**不是医学安全界限，也不是任意组合都自然的保证**；均相对绑定姿态，左右坐标经过标定。

| 关节 | 主摆动/屈伸 | 次摆动/侧偏 | 轴向扭转 |
| --- | --- | --- | --- |
| 锁骨 | -25～35° | ±25° | ±25° |
| 肩 | -110～140° | ±110° | ±95° |
| 肘/前臂 | 0～150° | 锁定 | ±80° |
| 腕 | ±70° | ±30° | ±25° |
| 髋 | -35～125° | ±55° | ±45° |
| 膝 | 0～155° | 锁定 | ±5° |
| 踝 | -50～30° | ±20° | ±20° |
| 骨盆 | ±25° | ±20° | ±30° |
| 各节脊柱 | -25～30° | ±20° | ±25° |
| 颈 | -35～45° | ±35° | ±60° |
| 头 | ±25° | ±20° | ±35° |

球关节两个摆动轴耦合为椭圆，不可同时到达表中两个最大值。头与颈、各节脊柱仍是分节范围，不是全身姿势相关先验。没有引入物理引擎、替换Three或复制Jolt代码；仅借鉴摆动/扭转分离思路，当前采用自行实现的旋转向量投影。候选研究/许可见[joint-limit-research.md](joint-limit-research.md)。

## A4：受限求解与统一命令

- 拖肘膝只转上臂/大腿；拖手脚只转小臂/小腿，肘膝固定，腕踝局部旋转保留、下游跟随。
- 两骨解析求解在上段受限后重算下段目标，再限制下段与末端朝向；输出合法可达结果和位置/朝向残差，不拉骨长，不解除限位。不是全局最优IK解的保证。
- 躯干复用Three CCD，但逐链节求解后立即投影约束，再更新世界矩阵进入下一节；原单手势预算仍是额外数值保护，不替代绑定参考范围。
- 骨盆移动复用双腿解析求解及可达区间搜索；同时检查保脚位置和朝向。不可达则缩短位移或保留起点；反馈限制原因及剩余位移。不能把恢复旧超限起点描述成自动修正成功。
- `pose.setBones`候选批量先验证，再经过同一投影后提交一次历史；返回实际旋转。自然模式仅允许根/骨盆位置改变，不能靠移动手脚局部位置绕过骨长。自由模式仍为显式高级制作选择。
- `session.inspect`/`rig.list`提供现有超限清单，未管理关节status=unmanaged、根status=root。模式属于当前模型编辑配置，不写素材格式；切模型重新选默认，普通已保存素材完全兼容。

输入是当前骨架、固定标定配置、候选局部旋转或拖动目标及模式；输出是受限局部姿态、实际修改反馈和求解残差。模型姿态和完整历史仍由工作台持有；显示控件、标定缓存不成为第二份可编辑姿势。
