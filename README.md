# MotionDeck

Windows 上的 3D 姿势与动作编排工具。可手动组合素材，也可让 AI 通过本机命令试摆、编排、截图检查并保存成果，无需云端服务或 Python 后端。

当前已发布 [v0.2.0 未签名测试版](https://github.com/mhdfy1988/motion-deck/releases/tag/v0.2.0)；技能独立版本为 `0.1.0`，随安装包提供。

2026-10-17 源码整理已收口，当前按用户授权准备v0.3.0未签名测试版，开发技能0.2.1。版本与待发布日志已冻结，正在构建并运行新产物完整验收；未发布前不将候选包当作公开最新版，不替换正式安装或用户资料。状态以[当前计划](docs/stages/current-todo.md)为准，证据见[验证记录](docs/verification.md)。

开发中未发布：新增无心跳协作状态及全应用操作提示，开发技能0.2.1；手动摆姿支持固定肘膝拖手脚、拖肘膝摆整条肢体、头胸腰联动、骨盆移动尝试保脚，以及旋转精调、撤销与保存。两内置骨架新增自然约束/自由编辑，旋转、拖动、求解及命令共用关节范围，旧素材不自动重写；不提供自动防穿模。不包含在公开安装包中，操作见[制作手册](docs/motion-authoring-guide.md)。

手动旋转使用有厚度的完整三轴圆环，双击关节点才打开，普通点击或拖动不弹环；“整体调整”中拖人物平移，双击人物才打开骨盆附近圆环，拖环旋转，点空白取消选择。姿势编辑从预览顶部进入，编辑中显示“退出编辑”，保存也在顶部；右侧仅编辑时展开调整/约束/历史，不重复显示保存退出，不提供数值微调或贴身名称浮标。播放栏跨整个预览区，只放预览操作，仍属未发布源码能力。

手部直接编辑（未发布）：点击手表面进入近景，再点某根手指才显示该指两个指节和指尖三点。三点均可拖动，分别只旋转近、中、远一节，上游不动，下游跟随；没有手部旋转环。返回全身恢复镜头，沿用约束、撤销及保存。无滑轨或预设，不提供自动防穿模。见[手部编辑](docs/references/hand-editing.md)。

观察相机（未发布试用）：当前只开放人物中心观察。空白左拖绕中心旋转，滚轮远近，中键平移；保持地面水平、有上下限位，松手停止。手部近景绕手观察，返回恢复原镜头；固定视图锁定旋转，编辑拖动优先。其他相机模式、飞行按键及旧右键观看暂时关闭。见[相机说明](docs/references/camera-trackball.md)。

旧动作若存在超限指节，自然模式首次真正拖动时仅校正当前一节后继续调整，可能先归位；点击不修正，取消/撤销仍恢复原姿势。自由模式不自动校正。

## 安装与更新

从 [GitHub Releases](https://github.com/mhdfy1988/motion-deck/releases) 下载 Windows x64 安装包。v0.2.0 文件名为 `MotionDeck-0.2.0-setup-x64.exe`，仅安装到当前用户，可选择目录并创建桌面快捷方式。不需要另装 Node 或浏览器。

没有代码签名证书，Windows 可能显示未知发布者提示；请核对下载来源及发布页 SHA256，不建议关闭系统安全防护。

在“设置 → 检查更新”检查并下载新版。下载完成、校验通过且确认“重启更新”后才安装；普通退出不会自动安装。安装、升级、卸载不会主动删除个人资料。免安装版不支持原位更新，需替换完整程序目录。详见[安装与更新](docs/install-and-update.md)。

升级前保存编排、备份素材库。新客户端可读取旧格式1/2；使用连续姿势或 AI 工作区后写为格式3/4，**旧客户端无法读取这些新资料**。降级程序不等于资料回退。

## 制作与编排

- 内置 Quaternius：117 个动作、99 个姿势；Mesh2Motion：162 个动作、16 个默认姿势。首次直接载入 Mesh2Motion，已有资料恢复上次模型。
- 模型导入与保存、动作/姿势搜索、预览、拖入时间轴、裁剪/变速、过渡、撤销/重做和保存自定义动作。
- 自定义动作/姿势可用铅笔按钮或 F2 改名；默认库只读。右键或 Ctrl+C/Ctrl+V 可从默认、第三方和自定义库复制到同类型自定义库，不覆盖原素材、不跨模型、不使用系统剪贴板。
- 连续关键姿势可零停留并共用平滑采样；水平/纵向整体位移独立控制，预览、轨迹、截图、录像和 GLB 共用输出策略，不改原素材。
- 多种固定视角、PNG 拍照、参考视频录制、带模型的 GLB/ZIP 导出。0.5× / 1× / 2× 仅改变播放与参考录像速度，不改编排片段时长。导出近似重采样，不承诺原曲线无损。

从左侧拖入动作或姿势，将过渡卡拖到片段之间。“裁剪”模式拖边缘保留部分原动作；“变速”模式拖边缘调整完整动作的播放时长。分割/两侧裁剪需要选中一个动作并将播放头放在片段内部。时间轴默认100像素/秒，增删片段不自动缩放；用缩放或“适合全部”调整显示。

过渡采用暖灰斜纹，选中片段使用亮蓝描边，两者独立。未保存编排不会跨重启恢复；保存后的动作才是可再次使用的成果。

## 让 AI 操作

安装目录提供 `MotionDeck-command.cmd` 和 `skills/motiondeck-director/`。将完整技能文件夹复制到 AI 工具的技能目录，再提供客户端位置及“设置”里的个人数据目录；详见[随包技能说明](skills/使用说明.md)。无需源码仓库或另装 Node。

正式客户端默认关闭控制。在设置中开启“命令控制”，再按需分别授权“姿势操作”和“编排操作”，权限仅限当前会话。命令与界面操作同一份模型和历史，可撤销；写入绑定当前模型和编辑版本，不接受任意代码或任意输出路径。

现有38条命令覆盖查询、动作/编排取帧、局部骨骼和整体变换、保存姿势、编排过渡、保存动作、PNG/轨迹检查、视频与 GLB 导出。制作流程见[姿势与动作制作手册](docs/motion-authoring-guide.md)，参数和授权见[命令说明](docs/command-control.md)。

AI 试验素材按任务保留在内部。检查后只推荐少量代表姿势和有效成品，用户逐个预览、复制到自定义库、改名或可恢复删除；不让密集修帧点淹没列表，不自动归类或删除旧自定义素材。见[AI 工作区](docs/ai-workspace.md)。

## 个人数据

个人设置默认在 `%APPDATA%\MotionDeck`，素材库、导出和备份默认在系统文档目录的 `MotionDeck` 下。设置支持打开目录、迁移素材库、更改导出/备份位置、备份恢复和清理缓存。程序目录与个人资料分离，切勿通过删资料或清浏览器存储排查显示问题。

仅复制、校验并备份本客户端旧 IndexedDB 资料后切换到 SQLite；原库保留。不迁移 Chrome 或动作工坊数据库，网页开发库也不与客户端共享。详细边界见[数据目录](docs/data-directories.md)。

## 开发与验证

使用 Node.js 24，在本仓库根目录执行：

```powershell
npm.cmd ci
npm.cmd start
```

开发入口自动构建并使用 `output/dev-preview/personal` 隔离资料，默认开放三项命令权限；此例外不进入正式包。网页仅用于本机开发与回归：`npm.cmd run dev` 使用 `http://127.0.0.1:8901/`，没有云端部署。

```powershell
npm.cmd run lint
npm.cmd run format:check
npm.cmd run build
npm.cmd run assets:verify
npm.cmd test
npm.cmd run desktop:installer
```

静态检查覆盖工作台与桌面源码；`npm.cmd run format`仅格式化显式清单内的十三个已整理文件，不整仓改写。范围和开发依赖见[项目结构](docs/project-structure.md#可读性与静态检查)。`npm.cmd run desktop:test:source`先构建，再运行独立资料下的隐藏源码桌面定向检查，不代替正式包验收。

预览CPU基准：`node scripts/benchmark-preview.mjs --output=output/performance/preview.json`。只运行隔离的合成骨架与真实源动作预览链路，不启动窗口或读取用户资料；结果不是渲染帧率，条件与本轮对比见[验证记录](docs/verification.md)。

免安装产物在 `output/desktop/MotionDeck-win32-x64/`，安装器在 `output/desktop/installer/`；保留完整目录，不只复制 EXE。发布前须完成当前配置的完整领域、网页、真实产物桌面及安装升级验收；不沿用旧版本的固定用例数或历史报告。具体环境、用例清单与报告要求见[本地验收](docs/references/local-acceptance.md)。GitHub 自动只运行基础构建、素材与领域检查，重型回归仅手动触发。

## 限制与文档

可见关节点使用3D标记，与模型和骨骼线同帧绘制；透明点击区独立，拖动/旋转/撤销逻辑不变，标记不进入素材和导出。

整体移动命中人物时显示手型和蓝色表面/轮廓高亮，拖动时加强；移开或退出恢复，仅编辑显示，不写入素材。

编辑姿势时切“整体调整”，直接拖人物让身体和手脚一起移动或腾空，无XYZ平移轴；沿当前观察平面移动，前后深度换视角再拖，空白仍可转动观察。支持一步撤销、Esc取消及随姿势保存。切回“摆姿”调关节，骨盆保脚与整体调整分开。

源码新增“编辑姿势”：手脚拖动固定肘膝、腕踝跟随；肘膝绕肩/髋摆整肢；头胸腰联动脊柱；骨盆移动并在腿部可达范围内尝试保脚。点击关节仍可旋转精调，一次手势一步撤销，Esc取消。仅骨盆及整体移动的唯一根允许局部平移，不改骨长/缩放。自定义/AI姿势保存需确认覆盖原姿势；动作取帧或默认姿势仍另存，默认素材不覆盖。此项尚未发布，旧包没有该入口。

公开v0.2.0没有关节范围约束；开发源码已有两内置模型的固定范围约束，但没有姿势相关的人体极限、全局脚底锁定、物理跳跃轨迹、MCP、跨模型重定向或跨平台安装。动作/姿势导入仍隐藏，全身联动入口仅为实验。自由编辑可超出范围；有限位仍可能穿模，数学/协议通过不等于动作自然，须检查过渡与连续播放。
