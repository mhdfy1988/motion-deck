# 随包技能

`motiondeck-director`用于让AI通过本机命令摆姿势、编排动作并检查效果。技能版本在`motiondeck-director/SKILL.md`的`metadata.version`中，与客户端独立编号。

将整个`motiondeck-director`文件夹复制到AI工具的技能目录。例如Codex通常使用`%USERPROFILE%\.codex\skills\`；设置了`CODEX_HOME`时使用其下的`skills`目录。已有同名技能先备份再替换，不要只复制`SKILL.md`。重新加载技能后，让AI使用`motiondeck-director`，并提供客户端安装位置和设置里的“个人数据”目录。

在MotionDeck设置中开启命令控制，并按需要授权姿势操作、编排操作。复制技能不会自动授权。其他AI工具须支持本地命令和读取本地图片；仅能聊天的网页版不能直接控制本机。

程序更新会替换安装目录内的随包技能，不会改动AI工具中的已复制版本；需要时手动更新。从客户端`0.2.0`起，安装版与免安装版的技能都在EXE旁的`skills`目录，命令入口为同目录的`MotionDeck-command.cmd`；旧`0.1.1`安装包没有此目录。
